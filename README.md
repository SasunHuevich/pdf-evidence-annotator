## Описание проекта

Данный сервис разработан в рамках технического задания на создание **инструмента ручной разметки evidence-регионов в PDF-документах** для мультимодальных RAG-систем и оценки ретриверов.

Сервис решает задачу сопоставления текстовых вопросов/ответов из датасета с их физическим визуальным расположением на страницах исходных документов.

### Основной функционал системы:
*   **Синхронизация с датасетом**: Загрузка исходных объектов разметки из `samples.json` и автоматическое отслеживание версий файлов (поддержка чтения из `output.sample.json`).
*   **Интеграция с Qdrant (Только чтение)**: Загрузка ранее существовавших регионов, bbox-координат и метаданных элементов из снапшота коллекции Qdrant по вычисляемому хэшу файла для отображения в интерфейсе разметки.
*   **Инструмент фиксации разметки**: Прием новых или отредактированных пользователем прямоугольных областей (`bbox`) и полная перезапись поля `evidence_regions` для конкретного вопроса.
*   **Асинхронное сохранение**: Локальное сохранение актуального состояния разметки в файл JSON на диске без блокировки основного потока выполнения HTTP-запросов.


## Подготовка к запуску и запуск

### Подготовка к запуску

- В корне проекта папку `qdrant_snapshots` и поместите туда файл выгруженный преподом. В докер-компос указал его точное название, поэтому проверьте там, что оно совпадает и тд. Это нужно для запуска Qdrant.
- Коллекцию pdf документов (папку data) поместите в корень проекта. Она необходима для запуска backend.
- Схему можно посмотреть по пути: `http://localhost:3000/swagger-ui`
- Собрать бэкенд скриптом `backend/build.sh`

### Запуск

Сервисы запускаются через docker-compose:
```sh
docker compose up -d --build
```

# Evidence Разметка - Frontend

Фронтенд для разметки evidence регионов на PDF документах.

## Требования

- Node.js 
- Запущенный бэкенд сервер на `http://localhost:3000`

## Подготовка к запуску

### 1. Перейти в директирию
```sh
cd frontend
```

### 2. Установить зависимости
```sh
npm install
```

### 3. Запуск
```sh
npm run dev
```

После запуска убедитесь, что frontend запущен на 5173 порте.

# Инструкция по использованию Evidence Разметка

Это приложение предназначено для **разметки evidence-регионов** (областей на страницах PDF-документов, содержащих ответы на вопросы). Вы можете выделять прямоугольные области на страницах PDF, которые соответствуют ответам на вопросы, и сохранять их.

---

## Начало работы

### Шаг 1: Запуск приложения

1. Откройте браузер и перейдите по адресу: `http://localhost:5173`
2. Вы увидите главный экран с выбором документа

### Шаг 2: Выбор документа

Есть два способа выбрать документ:

**Способ 1 - Из списка:**
- Нажмите на выпадающий список "Выберите документ"
- Выберите нужный PDF-файл из списка

**Способ 2 - Ввести вручную:**
- Введите имя файла в поле "Или введите имя файла"
- Нажмите кнопку "Загрузить"

### Шаг 3: Выбор вопроса

После загрузки документа в левой панели появится список вопросов:
- Нажмите на любой вопрос, чтобы начать разметку
- Вопросы содержат:
  - Текст вопроса
  - Номера evidence страниц (где нужно искать ответ)
  - ID вопроса

---

## Основные функции

### 1. Навигация по страницам

**В верхней панели есть кнопки навигации:**

| Кнопка | Действие |
|--------|----------|
| ◀ | Предыдущая страница |
| ▶ | Следующая страница |
| Показывает текущую страницу / всего страниц | Например: "5 / 10" |

**Также можно переключаться по evidence-страницам:**
- В блоке "О вопросе" нажмите на любую evidence страницу
- Приложение автоматически переключится на выбранную страницу

### 2. Режимы навигации

В правой части верхней панели есть кнопка переключения режимов:

| Режим | Описание |
|-------|----------|
| **Все страницы** | Свободная навигация по всем страницам документа |
| **Только evidence** | Навигация только по страницам, указанным для вопроса |


### 3. Работа с регионами

#### Типы регионов

| Тип | Цвет | Описание | Можно редактировать? |
|-----|------|----------|---------------------|
| **Регионы из Qdrant** | 🔵 Синие | Автоматически загруженные регионы |  Нет (только просмотр) |
| **Мои регионы** | 🟠 Оранжевые | Созданные вами регионы |  Да |

#### Создание региона

**Способ 1 - Режим рисования:**
1. Нажмите кнопку "Режим рисования" (станет зеленой)
2. Зажмите левую кнопку мыши на PDF
3. Выделите нужную область (появится красный прямоугольник)
4. Отпустите кнопку мыши - регион создан

**Способ 2 - Кнопка "Добавить регион":**
1. Нажмите кнопку "Добавить регион"
2. В центре страницы появится прямоугольник
3. Переместите его в нужное место и измените размер

#### Редактирование региона

**Для оранжевых регионов (моих):**

| Действие | Как сделать |
|----------|-------------|
| **Переместить** | Зажмите левую кнопку на регионе и перетащите |
| **Изменить размер** | Выделите регион (кликните на него), появятся угловые маркеры, перетаскивайте их |
| **Выделить регион** | Кликните на оранжевый регион (станет синим) |

**Синие регионы (из Qdrant) нельзя редактировать или удалять**

#### Удаление региона

1. Выделите оранжевый регион (кликните на него)
2. Нажмите кнопку "Удалить выбранный"
3. Регион будет удален

## Сохранение

### Что сохраняется?

Сохраняются **только ваши оранжевые регионы** со всех страниц, где вы их создали.

### Как сохранить?

1. Нажмите кнопку **"Сохранить мои регионы"** в правом верхнем углу
2. Кнопка показывает количество ваших регионов в скобках
3. После успешного сохранения появится уведомление: "Сохранено X пользовательских регионов"

### Где сохраняется?

Регионы отправляются на сервер и сохраняются в файле **output.sample.json** для текущего вопроса. Пусть к файлу data/output.sample.json.



1. **Регионы сохраняются** только при нажатии кнопки "Сохранить", изменения не теряются при переключении страниц

2. **При смене вопроса или документа** все ваши несохраненные регионы сбрасываются - сохраните их перед переключением!

3. **Оранжевый цвет** - ваши регионы (можно редактировать)
   **Синий цвет** - регионы из базы (только просмотр)
